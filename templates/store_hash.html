Digital Forensics Baseline Protocol
Registering a cryptographic MD5 baseline records an immutable signature in MySQL. If the file is already tracked, its baseline is updated. Any future unauthorized alteration or malware tampering will be detected by comparison against this baseline.

How It Works
  1. Baseline Registration: The calculated MD5 checksum is saved to the file_hashes table.
  2. Tamper Protection: If any byte of the file is modified by ransomware, attackers, or unauthorized scripts, its hash changes entirely.
  3. Verification: The Check Integrity tool verifies live files against this database baseline.
Storage Schema
